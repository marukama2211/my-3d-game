## Phase 1 — WebGL 初期化と3Dオブジェクト表示

**状態:** 実装済み。現環境で可能な自動・静的検証は完了。ブラウザ実行時の検証項目は未検証のため、Phase 全体は未完了。

### 実装内容

- `index.html` を Vite のアプリ入口として追加。
- Three.js の `WebGLRenderer`、シーン、透視投影カメラ、環境光と平行光を初期化。
- ライティングされた立方体を配置し、時間経過で回転させる。
- 画面サイズ変更に追従し、端末のピクセル比は最大2に制限。
- 初期化エラーを画面に表示する処理を追加。
- UIフォントの外部取得を避け、ネットワーク不要のシステムフォントを使用。
- テスト容易性のため、実際のシーンで使用する立方体・床・カメラの生成を名前付き関数に分けた。
- Three.js、TypeScript、Vite に加え、Node.js テストランナー用に `tsx`、Node 型定義を追加。
- 独自ベクトル・行列・変換処理、独自シェーダー、プレイヤー、入力、物理、ゲーム機能は実装していない。

### 自動・静的検証済み

- `npm install`: 成功。npm 監査結果は既知の脆弱性 0 件。
- `npm test`: 4件成功、0件失敗。
  - 立方体の頂点・法線・UVが有限値、頂点数が24、インデックス数が36、法線が単位長で、全インデックスが頂点範囲内であること。
  - 床円メッシュの頂点66個・インデックス192個、有限値、インデックス範囲、半径上限。
  - 実装で使うカメラのビュー行列・プロジェクション行列が有限で、原点がカメラ前方かつクリップ範囲内に投影され、near/far が WebGL NDC の -1/+1 に写ること。
  - 横長ビューポート比のカメラ設定が有限であること。
- `npm run build`: 成功。アプリとテストの TypeScript 型チェック、および Vite 本番ビルドを通過。
- 生成された本番 JavaScript に `node --check` を実行し、構文エラーがないこと。
- Three.js r180 の実装を静的確認。`WebGLRenderer` は `canvas.getContext("webgl2", ...)` を呼び、`WebGLProgram` / `WebGLShader` はシェーダー生成・コンパイル・リンク処理を持つ。
- アプリ独自のシェーダーや WebGL API 呼び出しはない。描画処理は Three.js に委譲している。
- 独自数学実装は存在しないため、自作 Vec/Matrix の単体テストは該当なし。カメラ行列は Three.js の実カメラを使って Node.js で数値検証した。

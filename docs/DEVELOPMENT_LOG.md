## Phase 2 — 数学ライブラリ

**状態:** 完了

### 実装内容

- `src/game/math/index.ts` にゲームコードから利用するThree.js数学型のエクスポート窓口を追加。
- `Vec2`、`Vec3`、`Vec4` はそれぞれ `Vector2`、`Vector3`、`Vector4` の別名。
- `Matrix3`、`Matrix4`、`Quaternion`、`Euler` をそのまま公開。
- `Transform` は `Object3D` の別名とし、position、rotation、quaternion、scale、matrix、親子変換を利用可能にした。
- 独自演算や独自データ型は重複実装せず、描画コードにも変更を加えていない。

### テスト・確認結果

- `npm test`: Phase 1・2合計8件成功、0件失敗。
- 数学テスト4件:
  - ベクトル別名がThree.jsの型を参照し、Vec2/3/4の基本演算が期待値になる。
  - Matrix3/Matrix4の合成・逆変換・分解と法線行列が有効。
  - Euler角とQuaternionから作る回転行列が一致し、Quaternionが単位長。
  - Transform(Object3D)のローカル変換と親子のワールド変換が一致。
- `npm run build`: 成功。アプリと全テストのTypeScript型チェックおよびVite本番ビルドを通過。
- このPhaseはブラウザ描画やDOMを使わない数学APIなので、Node.js上の自動テストで実行確認した。

### 残っている問題

- 自動テストとビルドで問題は見つかっていない。
- 独自数学アルゴリズムは実装していない。Three.jsを差し替える際は数学APIの利用箇所も見直す必要がある。
